# Tiny Garden · 小花园

A tiny, soothing flower-growing game made with plain HTML, CSS, and JavaScript. No build step, frameworks, or external assets.

## Play

Open `index.html` in a modern browser. On GitHub Pages, enable Pages for the repository's main branch and root folder, then open the published URL.

## What is inside

- Plant, water, grow, and harvest in a single-file mobile-first game
- Eight discoverable flower varieties with rarity levels
- A collection book and seed count saved in the browser with `localStorage`
- Original SVG/CSS plant art, generated Web Audio effects, and touch-friendly controls

## Made with

HTML · CSS · Vanilla JavaScript · SVG · Web Audio API
